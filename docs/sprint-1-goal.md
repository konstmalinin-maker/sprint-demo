# Sprint 1: MVP фитнес-трекера

## Sprint Goal

Реализовать базовую функциональность фитнес-трекера:
регистрацию и вход пользователя, журнал тренировок,
статистику, цели и напоминания.

## Definition of Done

- Код написан и запускается локально.
- Есть минимум один unit-тест для каждой фичи.
- Изменения оформлены через Pull Request.
- Выполнена проверка кода и оставлены review-комментарии.
- PR смержен в sprint-1.
- Документация обновлена при необходимости.

## Формат выполнения

Практическая работа выполняется индивидуально.
Роли Product Owner, Scrum Master и Developer
моделируются одним участником.
