# Sprint 1: MVP менеджера задач

## Sprint Goal
Создать базовую функциональность менеджера задач:
регистрацию и вход, создание и просмотр задач,
фильтрацию и статистику.

## Definition of Done
- Код написан и запускается локально.
- Для каждой функции есть хотя бы один юнит-тест.
- Выполнена самостоятельная проверка кода вместо ревью коллегой.
- PR объединён с sprint-1.
- README обновлён при необходимости.

Все функции реализует один исполнитель.

## Функции
- feature/user-auth — регистрация и вход.
- feature/task-list — просмотр списка задач.
- feature/task-create — создание задачи.
- feature/task-filter — фильтрация задач.
- feature/task-stats — статистика задач.
